# 최종 점검 (해당하는 항목만)

- [ ] 실제 과제의 필수 항목과 제출 파일명·위치를 다시 읽었다.
- [ ] 저장된 최신 파일이 제출 대상 경로에 있다.
- [ ] 화면/서버 과제라면 내장 Browser에서 실제 입력·버튼·페이지 이동을 확인했다.
- [ ] 실행한 명령과 결과를 적었고, 미실행/실패를 통과라고 표현하지 않았다.
- [ ] 분석이라면 원본 보존, 데이터 키·단위·분모·중복·검산을 확인했다.
- [ ] 모델이라면 라벨, 예측 시점, 누수, 기준선과 검증 분할을 확인했다.
- [ ] 비밀키와 시험 자료의 외부 전송 및 `git push`가 없었다.
- [ ] 외부 공개 키트 `sk-kit/` 및 `sk-kit/.git`이 과제 제출물에 잘못 섞이지 않는지 실제 제출 범위를 확인했다.
- [ ] 제출 확정 이후 수정이 불가능하다는 점을 알고 저장·검증을 마쳤다.
- [ ] 후속 서술형은 AI·복사 붙여넣기 없이 직접 작성한다.
