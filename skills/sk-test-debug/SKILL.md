# 작업 방식
문제를 발생시킨 **명령, 입력, 오류 메시지**를 먼저 확보한다. 원인을 한 번에 단정하지 않고 가장 가능성이 큰 가설부터 구분한다.

1. 현재 오류를 다시 실행해 동일 현상이 나는지 확인한다.
2. 원인을 설명하는 최소 파일·설정 범위를 찾는다.
3. 한 가지 수정 후 원래 실패 조건을 다시 테스트한다.
4. 수정과 연결된 기존 기능도 한 번 더 실행한다.

테스트가 성공하도록 검증값을 조작하거나 오류를 숨기지 않는다. 웹은 화면이 보인다는 사실만으로 버튼이나 저장 기능까지 검증했다고 쓰지 않는다. 데이터는 집계 단위·결측·중복·0분모 조건을 살핀다.
