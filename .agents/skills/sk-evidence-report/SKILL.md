# 목적
과제의 완료 여부를 말이 아니라 저장 파일과 실제 실행 기록으로 설명한다.

## 최종 연결
- 필수 요구 1개마다 결과가 있는 파일 위치와 확인 방법을 붙인다.
- 실행한 명령, 관찰한 출력, 미실행 테스트를 섞어 쓰지 않는다.
- 버그, 제약, 근거 없는 추정을 결과와 분리해 표시한다.
- 제출 경로·파일 이름·저장 상태가 과제의 안내와 같은지 마지막으로 확인한다.
- 공개 참고 키트, 비밀키, 금지된 자료가 제출물 또는 외부 업로드에 섞이지 않도록 확인한다.

별도 산출물이 요구되지 않았다면 기존 제출 문서나 간결한 실행 기록에 합쳐서 기록한다. 후속 서술형처럼 **AI 금지 단계에는 이 스킬을 사용하지 않는다.**
