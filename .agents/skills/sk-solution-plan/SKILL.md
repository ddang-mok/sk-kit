# 목적
기존 작업 공간에서 가장 짧게 검증 가능한 기능을 결정한다.

## 실행 전 판단
- 이미 제공된 언어, 실행 명령, 프레임워크, 데이터 구조를 조사한다.
- 필수 조건 가운데 사용자가 확인할 수 있는 최단 경로(입력 → 처리 → 출력)를 고른다.
- 추가 설치나 외부 서비스를 쓰기 전에 현재 환경에서 허용되는지와 대안을 확인한다.

## 단계별 계획 작성
각 단계마다 **변경 파일 → 보이는 결과 → 검증 명령**을 한 줄로 연결한다. 긴 아키텍처 설명보다 첫 번째 실행 결과를 먼저 만든다.

웹은 첫 화면에서 입력 하나를 처리하는 경로, 데이터 분석은 샘플 3~5행의 예상 집계, 모델은 단순 기준선부터 확인한다. 시간이 모자라면 필수 항목을 지키면서 선택 기능을 줄인다.
